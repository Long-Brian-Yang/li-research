# Structure files

## LiNbOCl₄

`LiNbOCl4_photo_reconstructed.cif` was reconstructed from two user-provided screenshots of a CIF editor. The screenshots showed:

- space group `Cmc2₁` (No. 36)
- `a = 3.996 Å`, `b = 12.565 Å`, `c = 12.765 Å`
- the seven displayed asymmetric-unit sites and their displayed occupancies

This file is a provisional model for inspection and model-building only. It must be compared against the original CIF before production DFT/MD because the screenshots do not expose every metadata field and partial occupancies require an explicit disorder/order treatment.
