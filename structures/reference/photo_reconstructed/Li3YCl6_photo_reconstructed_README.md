# Li₃YCl₆ structure file

`Li3YCl6_photo_reconstructed.cif` was reconstructed from two user-provided screenshots of a CIF editor. The screenshots showed:

- space group `P -3 m 1` (No. 164)
- `a = b = 11.2217 Å`, `c = 6.05517 Å`, `γ = 120°`
- the displayed Li, Y and Cl sites with partial occupancies

This is a provisional model for inspection and model-building only. It must be compared against the original CIF before production DFT/MD because partial occupancies require an explicit disorder/order treatment, and the screenshots do not expose every ADP and metadata field.
