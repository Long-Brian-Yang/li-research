# Li₃YCl₆ ordered (2\times2\times2) model — blocked

The screenshot-reconstructed CIF cannot currently be converted into a
chemically valid ordered model. Fully occupying its visible sites gives
Li₁₂Y₁₈Cl₁₈ after symmetry expansion, rather than Li₃YCl₆. Therefore no CIF or
LAMMPS data file is generated here.

The original deposited CIF, or an independently validated ordered/disordered
configuration model, is required before constructing the Li₃YCl₆ supercell.
