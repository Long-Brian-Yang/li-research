# Li₃YCl₆ ordered (2×2×2) model — ordering required

The screenshot-reconstructed CIF is a partially occupied average structure.
Its occupancy-weighted composition is close to Li₃YCl₆, but fully occupying all
visible alternative sites gives Li₁₂Y₁₈Cl₁₈. Those Y sites are mutually
exclusive disorder alternatives and must not all be placed simultaneously.

Therefore no CIF or LAMMPS data file is generated here yet. An
occupancy-resolved ordered configuration must be selected first, preserving
Li₃YCl₆ stoichiometry and checking minimum distances.

The original deposited CIF, or an independently validated ordered/disordered
configuration model, should be used as the source for the next step.
