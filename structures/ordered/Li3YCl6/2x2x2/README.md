# Li3YCl6 ordered 2x2x2 candidates

These candidates resolve the screenshot CIF into integer Li9Y3Cl18 cells
before expansion. Zero-occupancy Y sites are excluded; M1-M2 and M1-M3 Y
arrangements are represented, and Li sites are selected to approximate the
refined Li1/Li2 populations. Each 2x2x2 model contains 240 atoms:
Li72Y24Cl144.

Files in each model directory:

- ordered base-cell CIF
- ordered 2x2x2 CIF
- LAMMPS data with type order Li, Y, Cl
- validation JSON

These are ordered candidates, not final experimental disorder models. Relax
with MACE/DFT and compare multiple models before production MD. No overlap
deletion was used.
