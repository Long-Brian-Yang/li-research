# LiNbOCl₄ ordered (2\times2\times2) candidate

This directory contains a first-pass pipeline candidate generated from the
screenshot-reconstructed CIF. The model treats all visible sites as fully
occupied; after symmetry expansion the nominal formula is LiNbOCl₄ and the
minimum interatomic distance is checked before writing the files.

This is **not yet a production structure**. The original deposited CIF and the
experimental disorder model should be checked before reporting MD properties.

Files:

- `LiNbOCl4_ordered_2x2x2.cif`
- `LiNbOCl4_ordered_2x2x2.data`
- `LiNbOCl4_ordered_2x2x2.validation.json`
