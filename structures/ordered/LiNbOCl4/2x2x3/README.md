# LiNbOCl₄ ordered 2×2×3 candidate

This candidate is a direct 2×2×3 repeat of the explicitly occupied
screenshot-reconstructed conventional cell. It contains 336 atoms
(Li₄₈Nb₄₈O₄₈Cl₁₉₂) and is intended for validation, structural relaxation, and
then ML-MD.

The 168-atom cell reported in the literature uses a different crystallographic
setting. Therefore, this model should not be described as an exact 168-atom
replica until the cell setting is transformed and checked.

- `LiNbOCl4_ordered_2x2x3.cif`
- `LiNbOCl4_ordered_2x2x3.data`
