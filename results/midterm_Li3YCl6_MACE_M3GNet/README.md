# Midterm figures: Li₃YCl₆

Scope is intentionally limited to MACE-MPA-0 and M3GNet for the midterm presentation.

- `plots/Li3YCl6_MSD_600K_MACE_M3GNet.png`: 600 K MSD comparison.
- `plots/Li3YCl6_Arrhenius_MACE_M3GNet_exp_company.png`: MACE and M3GNet Arrhenius comparison, with reported experimental and NGK reference 300 K points.
- `tables/Li3YCl6_midterm_summary.csv`: numerical summary and provenance.

The MSD curves use the selected formal production trajectories. The Arrhenius curves use the existing formal multi-temperature summary; the experiment and NGK reference values are shown as reported 300 K reference points, not refitted temperature series.
