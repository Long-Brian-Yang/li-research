# Li₃YCl₆ full trajectory analysis

Generated from synchronized TSUBAME LAMMPS trajectories. `figures/` contains MSD, Li–Cl RDF, and Arrhenius plots; CSV files contain per-run and thermo summaries. RDF uses triclinic minimum-image coordinates. D is Li self-diffusion from a 20% discarded linear MSD fit; Arrhenius values are trajectory-level screening results.
