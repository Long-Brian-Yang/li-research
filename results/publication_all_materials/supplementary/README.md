# Supplementary analysis

This directory contains analysis outputs that support the main publication figures.

- `Li3YCl6/`: directional MSD, block-averaging diffusion uncertainty, RDF overview, Li-jump/Van-Hove analysis, and cell-stability analysis.
- `source_data/`: summary tables used for the Li₃YCl₆ analyses.
- `LiNbOCl4/`: reserved for the corresponding supplementary analysis when the same analysis set has been completed for LiNbOCl₄.

Trajectory files are intentionally excluded. The main publication figures remain one level above this directory.
