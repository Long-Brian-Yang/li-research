# Li₃YCl₆ publication figure package

## Directory layout

- `main/`: figures intended for the main manuscript/presentation.
- `supplementary/`: directional diffusion, block averaging, RDF, cell stability, and jump/Van Hove analyses.
- `source_data/`: numerical tables used to generate the figures.
- `plots/`: legacy publication exports retained for provenance; do not use for the final layout.

## Style

The newly generated MSD figures use the common presentation template: white background, black axes, consistent fonts and line widths, MACE-MPA-0 in blue, SevenNet-nano in green, and M3GNet in red. The remaining main figures are copied from the validated midterm set and will be regenerated with the same template when the final multi-model analysis is locked.

## Scope status

The current package contains the complete Li₃YCl₆ analysis set. LiNbOCl₄ figures are not added until the corresponding multi-temperature, three-model analysis is verified.
