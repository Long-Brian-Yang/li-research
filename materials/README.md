# Materials directory

Material files are divided by purpose:

- `candidates/`: construction inputs, relaxed structures and material-specific
  preparation records;
- `evidence/`: GitHub-safe structures and representative trajectories used by
  the maintained company report;
- `references/`: extracted literature structures or reference metadata.

For the current scientific narrative, start with
[`docs/materials/materials_overview_ja.md`](../docs/materials/materials_overview_ja.md)
or
[`docs/materials/materials_overview_en.md`](../docs/materials/materials_overview_en.md).
The evidence index maps every published figure to a clearly named structure or
trajectory without requiring the full raw trajectory archive.
