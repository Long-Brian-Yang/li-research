# 文献参考构造与当前候选的对照

日期：2026-09-11。**本目录是未松弛的文献衍生初始结构，不是已经合格的非晶结构。**

## 1. 如何参考文献构造

来源为 Kim et al., Nature Communications 16, 10678 (2025)，[DOI](https://doi.org/10.1038/s41467-025-65702-2)，Supplementary Data 4。采用 CC BY 4.0，原始文件保留在 `../../../references/kim_2025_lzoc/`。

1. 原晶胞 Li15 Zr6 Cl33 O3，57 原子。
2. 2×2×1 扩胞得到 Li60 Zr24 Cl132 O12，228 原子。
3. 固定种子 20260911 选取18个Cl，每个Cl与尚未移除的最近Li配对，删除18对LiCl。距离使用周期性最小镜像。
4. 保留全部 Zr/O 坐标及晶胞，得到 **Li42 Zr24 Cl114 O12，共192原子**，即 Li1.75ZrCl4.75O0.5。

这是可复现的电中性组分调整方法，不是最低能量空位搜索，也不保证删除位置最优。没有通过缩放坐标人为匹配某个实验密度。192与现有256原子体系具有相同组成比例，但属于不同尺寸；还不能公平比较扩散性能。

**判断：** 当前候选初始密度与文献衍生起点接近，但部分键距更短；没有依据单凭这些数字就认定结构已合理或已失效。文献起点提供了来源清楚的 Zr/O 框架参照。最终判断仍需当前候选完成降温、NPT及最小化后的结构，而非高温中间帧。

## 3. 文件与使用边界

- [target_unrelaxed.cif](target_unrelaxed.cif)：可视化参考。
- [target_unrelaxed.data](target_unrelaxed.data)：LAMMPS atomic格式；type 1=Li、2=Zr、3=O、4=Cl。
- [comparison.json](comparison.json)：原始文件SHA256、移除原子索引、seed、组成、密度与距离。
- 脚本：`scripts/structures/build_lzoc_reference.py`；验证：`tests/test_lzoc_reference.py`。

JSON中的配位数采用固定诊断截断，并非RDF第一极小值确定的正式配位数；不应用于发表结论。CIF读取和距离计算使用ASE，保留非正交晶胞和周期边界。
