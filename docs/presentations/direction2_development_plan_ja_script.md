# 方向2：固体電解質（こたいでんかいしつ）の計算開発計画（けいさんかいはつけいかく）

## 企業向け発表原稿（きぎょうむけはっぴょうげんこう）（約5分）

### 1. はじめに

方向2について説明（せつめい）します。

### 2. 現在（げんざい）の計算（けいさん）における課題（かだい）

NGK様（さま）から頂（いただ）いたデータを分析（ぶんせき）したところ、以下（いか）の三（みっ）つの課題（かだい）があります。

一、精度（せいど）の検証（けんしょう）ができていません。

二、計算環境（けいさんかんきょう）の再現性（さいげんせい）の確保（かくほ）が困難（こんなん）です。

三、現在（げんざい）のモデルでは、長時間（ちょうじかん）のMD計算（けいさん）への対応（たいおう）が難（むずか）しいです。

### 3. 解決案（かいけつあん）

企業内（きぎょうない）の初期環境（しょきかんきょう）は、M3GNetをLAMMPSのCPUで実行（じっこう）する方法（ほうほう）です。したがって、最初（さいしょ）の比較（ひかく）はASEとLAMMPSではなく、LAMMPSのCPUとGPUの比較（ひかく）です。その後（ご）、M3GNet、MACE、SevenNetなどのモデル比較（ひかく）へ進（すす）みます。

まず、MACEは、原子（げんし）の周（まわ）りの方向性（ほうこうせい）や多体相互作用（たたいそうごさよう）も扱（あつか）いやすいモデルです。

今回（こんかい）は、同（おな）じM3GNet–LAMMPS計算（けいさん）をCPUからGPUへ移（うつ）す効果（こうか）を最初（さいしょ）に確認（かくにん）します。240原子（げんし）の短時間（たんじかん）ベンチマークでは、CPUは3.285 steps/s、GPUは56.621 steps/sで、約（やく）17.2倍（ばい）の高速化（こうそくか）でした。これは速度（そくど）の結果（けっか）であり、精度（せいど）が向上（こうじょう）したという意味（いみ）ではありません。

### 4. 今回（こんかい）の開発対象（かいはつたいしょう）

対象材料（たいしょうざいりょう）は、Li₃YCl₆とLiNbOCl₄です。

二つとも高いLi⁺伝導度（でんどうど）が報告（ほうこく）され、実験（じっけん）データがありますので、計算結果（けいさんけっか）の精度検証（せいどけんしょう）が可能（かのう）です。

### 5. 計算ワークフロー

計算（けいさん）は、次の四（よっ）つのSTEPで行（おこな）います。

第一に、構造選定（こうぞうせんてい）です。Li₃YCl₆とLiNbOCl₄を使（つか）います。

第二に、既存（きそん）のM3GNet–LAMMPS CPU環境（かんきょう）を再現（さいげん）し、LAMMPS GPUとの速度（そくど）を比較（ひかく）します。その後（ご）、MACEなどの候補（こうほ）モデルを比較（ひかく）します。

第三に、Tsubame GPU対応（たいおう）のLAMMPSを用（もち）いて、MDで原子（げんし）の動（うご）きを計算（けいさん）します。

第四に、Li⁺拡散（かくさん）と伝導度（でんどうど）を評価（ひょうか）し、実験値（じっけんち）と比較（ひかく）します。

### 6. まとめ

現在（げんざい）の企業内計算（きぎょうないけいさん）には、精度検証（せいどけんしょう）、計算環境（けいさんかんきょう）の再現性（さいげんせい）、長時間（ちょうじかん）MDの計算効率（けいさんこうりつ）という課題（かだい）があります。

最終的（さいしゅうてき）には、この計算（けいさん）ワークフローを他（ほか）の固体電解質候補（こたいでんかいしつこうほ）にも展開（てんかい）し、NGK様（さま）の今後（こんご）の材料探索（ざいりょうたんさく）に活用（かつよう）いただける計算手法（けいさんしゅほう）として整理（せいり）することを目指（めざ）します。

以上（いじょう）です。
