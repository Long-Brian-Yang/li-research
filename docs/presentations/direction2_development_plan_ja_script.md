# 方向2：固体電解質（こたいでんかいしつ）の計算開発計画（けいさんかいはつけいかく）

## 企業向け発表原稿（きぎょうむけはっぴょうげんこう）（約5分）

### 1. はじめに

方向2について説明（せつめい）します。

まず、現在（げんざい）使われているモデルを更新（こうしん）し、MACEとLAMMPSを用（もち）いて、二つの代表構造（だいひょうこうぞう）について、結晶構造（けっしょうこうぞう）からMD計算（けいさん）までの再現可能（さいげんかのう）な汎用（はんよう）モデルを完成（かんせい）させます。

### 2. 現在（げんざい）の計算（けいさん）における課題（かだい）

企業側（きぎょうがわ）から頂（いただ）いた既存（きそん）の計算結果（けいさんけっか）を分析（ぶんせき）したところ、主（おも）に以下（いか）の課題（かだい）があると考（かんが）えています。

第一（だいいち）に、精度（せいど）の検証（けんしょう）ができていません。計算結果（けいさんけっか）を論文値（ろんぶんち）や実験値（じっけんち）と比較（ひかく）する必要（ひつよう）があります。

第二（だいに）に、計算環境（けいさんかんきょう）の再現（さいげん）が困難（こんなん）です。担当者別（たんとうしゃべつ）に計算環境（けいさんかんきょう）が異（こと）なる場合（ばあい）があります。

第三（だいさん）に、現在（げんざい）の計算（けいさん）モデルが、長時間（ちょうじかん）のイオン輸送（ゆそう）MDに適（てき）しているかを確認（かくにん）する必要（ひつよう）があります。

### 3. 解決案（かいけつあん）

解決案（かいけつあん）として、M3GNetからMACEへの変更（へんこう）、ASE-MDからLAMMPSへの変更（へんこう）を検討（けんとう）しています。

MACEは、現在（げんざい）使用（しよう）しているM3GNetと比（くら）べて、主（おも）に三（みっ）つの利点（りてん）があります。

第一（だいいち）に、equivariant message-passingにより、局所環境（きょくしょかんきょう）の方向性（ほうこうせい）や多体相互作用（たたいそうごさよう）を表現（ひょうげん）しやすい点（てん）です。

第二（だいに）に、MPTrjに加（くわ）えてsAlexも用（もち）いて学習（がくしゅう）され、89元素（げんそ）をカバーしているため、今回（こんかい）対象（たいしょう）とする全（すべ）ての元素（げんそ）を一（ひと）つのモデルで扱（あつか）える点（てん）です。

第三（だいさん）に、LAMMPSのGPU backendに接続（せつぞく）でき、構造緩和（こうぞうかんわ）から長時間（ちょうじかん）MDまで同（おな）じモデルを一貫（いっかん）して使用（しよう）しやすい点（てん）です。

LAMMPSは、現在（げんざい）使用（しよう）しているASE-MDと比（くら）べて、主（おも）に三（みっ）つの利点（りてん）があります。

第一（だいいち）に、コンパイル済（ず）みのMD engineとGPU backendを利用（りよう）できるため、TSUBAME上（じょう）で大規模（だいきぼ）・長時間（ちょうじかん）のMDを効率（こうりつ）よく実行（じっこう）しやすい点（てん）です。

第二（だいに）に、ensemble、restart、trajectory dumpなどの機能（きのう）が標準（ひょうじゅん）で用意（ようい）され、計算（けいさん）の再開（さいかい）と条件管理（じょうけんかんり）がしやすい点（てん）です。

第三（だいさん）に、Liのunwrapped trajectory、MSD、温度（おんど）、エネルギー、圧力（あつりょく）などを一定間隔（いっていかんかく）で保存（ほぞん）でき、拡散挙動（かくさんきょどう）と構造（こうぞう）・熱力学的安定性（ねつりきがくてきあんていせい）を同（おな）じworkflowで評価（ひょうか）できる点（てん）です。

### 4. 今回（こんかい）の開発対象（かいはつたいしょう）

対象材料（たいしょうざいりょう）は、Li₃YCl₆とLiNbOCl₄です。

二（ふた）つとも高（たか）いLi⁺伝導度（でんどうど）が報告（ほうこく）され、実験（じっけん）データがありますので、計算結果（けいさんけっか）の精度検証（せいどけんしょう）が可能（かのう）です。

### 5. 計算ワークフロー（けいさんワークフロー）

STEP1は、次（つぎ）の順番（じゅんばん）でTSUBAME上（じょう）で実施（じっし）します。

1. 論文構造（ろんぶんこうぞう）を基（もと）に有序構造（ゆうじょこうぞう）モデルを作成（さくせい）する。
2. 二（ふた）つの材料（ざいりょう）についてスーパーセルを構築（こうちく）する。
3. MACEを用（もち）いて構造緩和（こうぞうかんわ）を行（おこな）う。
4. 固定温度（こていおんど）でFIRE法（ほう）などにより、イオン位置（いち）を最適化（さいてきか）する。
5. 最適化構造（さいてきかこうぞう）を用（もち）いて、LAMMPSでMD計算（けいさん）を行（おこな）う。
6. Li原子（げんし）のMSDからLi⁺拡散係数（かくさんけいすう）を評価（ひょうか）する。
7. 計算結果（けいさんけっか）を論文値（ろんぶんち）および実験値（じっけんち）と比較（ひかく）する。

現在（げんざい）のMD条件（じょうけん）は、400 K、NVT、timestep 1 fs、equilibration 10 ps、production 100 psです。

### 6. まとめ

現在（げんざい）の企業内計算（きぎょうないけいさん）には、精度検証（せいどけんしょう）、結果（けっか）の解釈（かいしゃく）、計算環境（けいさんかんきょう）の再現性（さいげんせい）、長時間（ちょうじかん）MDの計算効率（けいさんこうりつ）という課題（かだい）があります。

このworkflowを他（ほか）の固体電解質候補（こたいでんかいしつこうほ）にも展開（てんかい）できるようにし、企業（きぎょう）での今後（こんご）の材料探索（ざいりょうたんさく）に利用（りよう）できる計算手法（けいさんしゅほう）として整理（せいり）することを目指（めざ）します。

以上（いじょう）です。
