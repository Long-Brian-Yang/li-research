## 1. 文献調査・整理

Li–Zr–O–Cl 系に関する3編の論文を読み、材料合成とイオン伝導特性、非晶質の局所構造、実験と DFT/AIMD を組み合わせた構造・輸送解析について整理した。

- Kim et al., Nature Communications（2025）：構造評価と DFT/AIMD を組み合わせた研究。[DOI](https://doi.org/10.1038/s41467-025-65702-2)

[英語版レポート](../literature/lzoc_top3/reading_report_en.md)と[日本語版レポート](../literature/lzoc_top3/reading_report_ja.md)を作成し、今後の研究計画を加えて GitHub に保存した。各論文では組成と手法が異なるため、実験値を区別して扱う。

## 2. 非晶質材料の構造作製の試行

文献で公開された原子座標を基に、異なる初期配置を持つ **Li₁.₇₅ZrCl₄.₇₅O₀.₅** の候補モデルを3つ作製した。各モデルは **192 原子**で構成される。TSUBAME 上で MACE-MPA-0＋LAMMPS を使用し、初期エネルギー最小化、高温混合、冷却、定温保持、NPT 緩和を実施している。

作製手順：初期最小化 → 1500 K での混合10 ps → 300 K までの冷却30 ps → 300 K での保持5 ps → NPT 緩和10 ps → 最終最小化。構造作製の MD 時間は合計55 psであり、最小化の計算時間は別途必要となる。

3つのモデルは関連する文献構造から派生した異なる初期配置であり、独立に生成した3つの非晶質レプリカではない。従来の256原子モデルの計算は停止し、取得済みデータは保持した。

## 4. 今後の予定

計算終了後、最終緩和の収束、原子間距離、密度変化、局所構造を確認し、妥当な候補を1つ選定する。確認を通過した後、50 psの平衡化＋200 psの本計算を行う予定である。本計算の温度は別途決定し、この段階のジョブはまだ投入していない。
