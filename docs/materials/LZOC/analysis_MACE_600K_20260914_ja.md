# 進捗報告：非晶質 LZOC の MACE-MPA-0 MD 計算（600 K）

> Historical record / 历史记录：保留记录当时的设置与判断，不作为实时任务状态。参见 [材料文档索引](README.md)。

報告日：2026年9月14日

対象：Li₁.₇₅ZrCl₄.₇₅O₀.₅（LZOC）

解析対象：TSUBAME job 8635176.1、600 K、Replica 1

数値：2026年9月12日に保存・照合した解析結果に基づく。本報告の作成時に新たな MD 計算は実施していない。

## 1. 今回の目的

作製した非晶質構造を用いて、MACE-MPA-0 と LAMMPS による 600 K の MD 計算を行い、Li の移動と構造の安定性を確認した。計算は正常に終了したが、体積膨張と骨格原子の移動が認められたため、拡散係数は現段階では探索的な推定値として扱う。

## 2. 計算条件

| 項目 | 条件 |
|---|---|
| ポテンシャル | MACE-MPA-0 |
| 実行方法 | LAMMPS / ML-IAP、GPU |
| 初期構造 | 候補 3 の 300 K 平衡化後構造 |
| 原子数 | 192 原子：Li 42、Zr 24、O 12、Cl 114 |
| 境界条件 | 三次元周期境界 |
| 時間刻み | 0.5 fs |
| 昇温 | 300 → 600 K、NVT、10 ps |
| 平衡化 | 600 K、1 bar、NPT、50 ps |
| 本計算 | 600 K、NVT、200 ps |
| 温度・圧力制御 | Nosé–Hoover 系、Tdamp 0.1 ps、Pdamp 1 ps |
| 本計算の体積 | NPT 最終フレームの晶胞を固定 |
| 独立構造数 | 1 構造、1 計算 |

50 ps の平衡化時間を設定したこと自体は、密度や構造の収束を保証しない。

## 3. 温度と体積

| 指標 | 結果 |
|---|---:|
| 本計算の平均温度 | 598.89 K |
| 温度のフレーム標準偏差 | 35.03 K |
| 300 K 初期構造の密度 | 1.9139 g/cm³ |
| 600 K 本計算の密度 | 1.4683 g/cm³ |
| 初期構造に対する体積増加 | 30.3% |

平均温度は設定温度と整合している。一方、NPT 過程で体積が大きく増加した。初期密度は実験値ではなく、今回の構造モデルの値である。そのため 30.3% を実験的な熱膨張率とは呼ばない。また、その後の NVT で体積が一定なのは計算条件によるものであり、密度の妥当性を示す証拠ではない。

本計算の前半 50 ps と後半 50 ps の平均ポテンシャルエネルギー差は −0.237 eV／系であった。ただし、エネルギーの変化が小さいことだけで骨格の安定性は判断できない。NVT 計算は NVE のエネルギー保存試験ではない。

## 4. Li の MSD と拡散係数

200 ps の本計算から、全 42 個の Li の時間原点平均 MSD を求めた。周期境界をまたぐ座標を用い、全体系の質量重み付き重心移動を除いた。

$$
\mathrm{MSD}_{\mathrm{Li}}(\tau)
=\left\langle\left|\mathbf r_i(t+\tau)-\mathbf r_i(t)\right|^2\right\rangle_{i,t}
$$

ここで、i は Li 原子、t は時間原点、τ は時間差（lag time）である。三次元で正常拡散が成立する場合、MSD の傾き a から D = a/6 を求める。

$$
\mathrm{MSD}_{\mathrm{Li}}(\tau)\simeq a\tau+b,
\qquad D_{\mathrm{Li}}=\frac{a}{6}
$$

1 Å²/ps = 10⁻⁴ cm²/s として単位換算した。切片 b を含む線形フィットで、**lag time 20–80 ps** を使用した。これは「軌跡の 20–80% を抽出する」という意味ではない。

| 指標 | 結果 |
|---|---:|
| 拡散係数の暫定推定値 | 1.7197 × 10⁻⁵ cm²/s |
| MSD 線形フィット R² | 0.9965 |
| log(MSD)–log(τ) の傾き α | 0.777 |
| 検討した複数 lag 区間での D の範囲 | (1.720–2.236) × 10⁻⁵ cm²/s |

R² は高いが、正常拡散で期待される α ≈ 1 より小さい。したがって、良好な直線フィットだけを根拠として拡散係数が十分収束したとは判断できない。上記の範囲はフィット区間依存性であり、統計的な信頼区間ではない。

**この単温度計算だけから活性化エネルギー Eₐ や 300 K の外挿値は求めない。**

## 5. 骨格の安定性

次の値は全体系の重心移動を除いた、本計算開始時から 200 ps 後までの単一時間原点 MSD である。前節の時間原点平均 MSD とは定義が異なる。

| 元素 | MSD(200 ps) / Å² |
|---|---:|
| Li | 218.70 |
| Zr | 58.32 |
| O | 43.18 |
| Cl | 92.74 |

Li だけでなく Zr、O、Cl も移動している。さらに Zr 自身の重心移動を差し引いても Zr の MSD は 57.97 Å² であり、単なる系全体の平行移動では説明できない。

周期境界を考慮した近接原子の比較では、初期 Zr–O 対の末フレーム保持率は 100%、Zr–Cl 対は 64.8% であった。共通の診断用距離閾値は Zr–O 2.6 Å、Zr–Cl 3.0 Å とした。この保持率は始点と終点の比較であり、連続的な結合寿命ではない。

局所配位の平均値は比較的維持されている：

| 平均配位数 | 本計算 0–50 ps | 本計算 150–200 ps |
|---|---:|---:|
| Li–Cl（3.2 Å 以下） | 3.744 | 3.666 |
| Zr–Cl（3.0 Å 以下） | 4.435 | 4.442 |

以上より、局所的な配位単位が残っていても、骨格原子の移動や近接原子の入れ替わりが起きていると考えられる。RDF や平均配位数が大きく変化しないことだけでは、安定な固体骨格が維持されたとは結論できない。ただし、現時点の解析だけで融解や化学分解が起きたと断定することもできない。

## 6. 現段階の結論と次の対応

- 温度制御とプログラム実行は確認できた。
- Li の移動は観測されたが、約 30% の体積膨張と骨格移動を伴う。
- この D は探索的な結果として保存し、安定な非晶質固体の確定値とは扱わない。
- 次は参考密度・局所構造との照合、および現在の構造での MACE のエネルギー–体積・応力評価を優先する。
- NEP89 の比較計算は別途進めているが、膨張が小さいことだけで正しいモデルと判断しない。

## 7. 発表用の短い説明

> 今回は、192 原子の非晶質 LZOC に対して、MACE を用いた 600 K の MD 計算を実施しました。50 ps の NPT 平衡化後に 200 ps の NVT 計算を行い、平均温度は約 599 K でした。Li の MSD から得た拡散係数の暫定値は約 1.72 × 10⁻⁵ cm²/s です。一方、初期構造に対して約 30% の体積膨張が見られ、Zr や Cl の移動も確認されました。そのため、現段階では安定な固体中の Li 拡散として結論せず、密度と骨格の妥当性を優先して確認しています。
