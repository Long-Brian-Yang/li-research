# 非晶 Li₃PS₄ 独立研究工作包

更新日期：2026-09-16

## 1. 研究定位

本工作将非晶 Li₃PS₄ 从多材料筛选中的“方法对照”提升为一个独立研究对象。核心问题不是简单证明 NEP89 能够运行，而是回答：

> 通用预训练势 NEP89 能否同时再现 Li₃PS₄ 玻璃的局部结构、热激活 Li 输运及无序促进扩散的机制？

这一问题可以形成清晰的研究故事：先验证玻璃结构，再比较输运绝对值与温度趋势，最后通过晶态／玻璃态对照判断“无序促进扩散”是否被同一计算框架再现。

## 2. 文献基准

### 2.1 主要计算基准

Chen 等的工作比较了晶态、玻璃态与玻璃陶瓷 Li₃PS₄，并用 AIMD 数据训练的深度势研究300–900 K的Li运动。论文将无序局部环境、Li跳跃以及增强的扩散联系起来，是本工作的主要计算参照。

- Chen et al., *Disorder-induced enhancement of lithium-ion transport in solid-state electrolytes*, **Nature Communications 16, 1057 (2025)**.
- DOI：[10.1038/s41467-025-56322-x](https://doi.org/10.1038/s41467-025-56322-x)
- 本项目可直接比较：玻璃结构、Li MSD、扩散系数、温度趋势、局部配位及骨架运动。
- 不能直接声称复现：作者的材料专用DeePMD精度、完整softness模型，以及未按原始输入严格重建的玻璃陶瓷结构。

### 2.2 实验输运基准

实验文献用于约束室温电导率的数量级，但实验电导率不能直接等同于MD自扩散系数。若进行Nernst–Einstein换算，必须明确其忽略离子相关性。

- Mirmira et al., Li₃PS₄实验输运参照，**Journal of Materials Chemistry A (2021)**.
- DOI：[10.1039/D1TA02754A](https://doi.org/10.1039/D1TA02754A)

### 3.3 制备依赖性与替换决定

新选择的R1玻璃在300 K的结构检查已完成：

- 平均温度：300.52 K；
- 平均压力：0.0023 GPa；
- 密度由2.210变化至2.205 g/cm³；
- P–S平均配位数为4.000，四配位比例为1.000；
- 最小周期距离为1.902 Å。

R1的300／500／700／900 K计算与远端分析已经完成，每个温度采用10 ps温度调整、50 ps NPT和200 ps NVT production。原始轨迹保留在TSUBAME，仅轻量CSV、JSON和最终图同步到仓库。R1在输运结果检查前已经确定，因此不是按文献接近度挑选。

与旧系列相比，R1的700和900 K表观D分别为0.98和0.85倍，而300 K高7.56倍、500 K低至0.59倍。这说明低温斜率对制备结构和有限采样非常敏感，高温偏差则较系统。500／700／900 K诊断回归给出$E_a=0.4189$ eV，但500 K仍为亜扩散，因此不作为正式活化能。综合Material Review已用R1替换旧主图；旧系列保留为制备依赖性记录。

## 4. 建议形成的独立研究主线

### 研究问题A：NEP89是否保持合理的Li₃PS₄玻璃网络？

先判断P–S四面体是否保持，再讨论Li输运。主要分析包括：

1. P–S、Li–S、P–P和S–S分波RDF；
2. P–S配位数分布，而不只报告平均值；
3. S–P–S与P–S–P角度分布；
4. Qⁿ或等价的PS₄连接类型统计；
5. 静态结构因子S(q)，在定义和散射权重一致时与文献比较；
6. 玻璃密度、势能与压力稳定性。

核心判据是短程PS₄单元和中程连接性同时合理。单个RDF峰位置接近不足以证明玻璃结构已经复现。

### 研究问题B：NEP89是否再现文献的Li输运温度趋势？

以R1为正式结构，统一计算：

1. 300／500／700／900 K完整Li MSD；
2. 同一物理定义下的D(T)；
3. 仅使用出现稳定扩散区间的温度进行Arrhenius分析；
4. 表观活化能Eₐ；
5. 条件性Nernst–Einstein电导率，并与实验电导率分开呈现；
6. 不同时间块的斜率稳定性，判断低温轨迹是否足够长。

300 K若仍未出现扩散区间，应报告“在当前时间尺度内未解析”，而不是强行给出室温D。优先依据500–900 K或700–900 K的有效区间讨论高温趋势，并明确温度点数量带来的不确定性。

### 研究问题C：扩散来自Li跳跃还是骨架共同重排？

建议在MSD之外加入：

- Li、P、S元素分辨MSD；
- self van Hove函数，区分局部振动和离散跳跃；
- distinct van Hove函数，判断协同或交换行为；
- non-Gaussian parameter，识别动力学异质性；
- Li跳跃距离、跳跃频率和residence time；
- Li–S配位变化与后续位移的关联；
- Li迁移通道的空间占据图或概率密度。

若Li MSD增长而P/S骨架基本稳定，可讨论固态网络中的Li迁移；若高温下骨架MSD同步显著增长，则应表述为热诱导网络重排参与的表观输运。

### 研究问题D：无序是否确实增强Li输运？

这是最适合发展成独立工作的核心比较。建议在同一NEP89／GPUMD设置下建立：

1. 晶态β-Li₃PS₄；
2. 当前玻璃态Li₃PS₄；
3. 可选的玻璃陶瓷模型。

三者使用相同原子数量级、温度点、平衡与分析定义。比较内容包括：

- D(T)与Eₐ；
- Li位点分布及迁移通道；
- Li–S配位分布；
- van Hove与非Gaussian参数；
- P–S网络连接性；
- 骨架运动。

只有在同一模型体系中观察到玻璃相的结构无序、Li动力学异质性与扩散增强同步出现，才能较有力地复现Chen论文的中心故事。

### 研究问题E：偏差来自结构，还是来自势函数转移性？

本项目已有12个同组成3000 K CP2K/PBE-D3构型，可作为有限的能量／力检查样本。它们不能代表室温玻璃，但可以检查NEP89在Li–P–S高温构型上的基础误差。建议：

1. 计算NEP89能量与力误差；
2. 按Li、P、S元素分解力误差；
3. 检查大力原子和短距离环境；
4. 将势函数误差与RDF、骨架运动及D偏差联系起来；
5. 若材料专用DeePMD模型可以直接运行，再进行同一初始结构的NEP89–DeePMD对照。

这一步可以区分“制备出的玻璃不同”与“相同类型构型上势函数响应不同”，但12帧不足以建立完整精度结论。

## 5. 工作优先级

|优先级|工作|是否需要新MD|主要产出|
|---:|---|---|---|
|完成|远端分析R1四温度结果|否|MSD、D(T)、结构稳定性表|
|完成|将R1与旧系列及Chen玻璃结果直接比较|否|输运图与偏差表|
|完成|R1的RDF、配位、角度和骨架MSD|否|结构—输运对应图|
|P1|计算self van Hove、non-Gaussian参数和跳跃统计|否|扩散机制图|
|P1|建立β-Li₃PS₄晶态对照并运行匹配温度MD|是|晶态—玻璃态核心对照|
|P2|若300 K仍无扩散，延长低温production|是，条件性|低温分辨能力检查|
|P2|建立玻璃陶瓷模型|是，可选|三相比较|
|P2|NEP89与公开材料专用DeePMD同构型比较|视模型可用性|势函数转移性证据|

现阶段无需立即重跑相同四温度。下一步优先级转为机制分析和晶态—玻璃态对照；只有研究问题明确需要室温D时，才考虑延长低温轨迹。

## 7. 建议的最终论文／汇报故事

1. 文献提出无序可以提高Li₃PS₄中的Li迁移；
2. 本工作用无需材料专门训练的NEP89重建512原子玻璃并扩展到长时间MD；
3. NEP89保持PS₄短程结构，但当前独立制备系列仍高估高温Li扩散，且高温骨架运动不可忽略；
4. 与旧系列对照表明低温斜率具有明显制备依赖性；
5. 通过同一势函数下的晶态—玻璃态对照检验“无序增强”是否可迁移复现；
6. 结合机制指标和有限DFT构型检查，判断偏差主要来自玻璃结构、势函数还是二者共同作用。

最终结论不应是“NEP89比文献得到更好的电解质”，而应是：

> 通用预训练势能够以较低成本捕捉Li₃PS₄玻璃的部分结构与热激活动力学，但其定量输运能力取决于对P–S网络和Li局部环境的转移精度；当前制备复核已经揭示低温采样敏感性，而晶态—玻璃态对照仍决定其能否再现无序增强机制。
