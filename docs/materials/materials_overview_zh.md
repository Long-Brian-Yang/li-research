## 4. 建议优先级：收敛路线，不再同时扩张

这是规划建议，不代表已授权提交下列新计算。

1. **主线 A：新 LZOC**。最接近现有 Zr–O–Cl 方向。先整理已完成冷却输出，检查残余压力、框架重排、配位和低温秩序；有明显异常时先诊断，不直接追加多温度 diffusion。
2. **主线 B：LSZC**。已有作者结构和实验背景。先对照作者非晶 Data 2 与当前 272 原子种子的构建差异，决定能否有依据地重建小模型；300 K 压缩／卸压不能替代非晶制备。
3. **方法对照：Li₃PS₄**。复用已有 611 ps 结果完善验证；作为硫化物玻璃方法基准，不取代氧氯化物主线。不要仅为增加论文协议数量再重复制备。
4. **待问题解决：LiPON**。优先读完当前卸压检查；若短 N–N 等异常仍存在，应检查势函数与结构化学，不通过反复延长 MD 掩盖。
5. **旧 LZOC 候选 3：归档对照**。保留结构、轨迹及异常分析，不删除，也不继续扩大温度矩阵。

### 每条路线进入正式扩散计算前

- 固定一个可追溯结构：组成、原子数、来源、随机种子、结构文件和势函数 hash。
- 建立“文献参数／实际参数／改动理由”表；不同文献分支不可默默拼接。
- 检查完整日志、温度、分块能量／密度／压力趋势；NVT 密度恒定不是收敛证据。
- 检查非晶性及局部化学：RDF/结构因子或有序性指标、框架位移、配位、短距离异常；不设未经依据的通用合格阈值。
- 与相同组成、相关温度结构的 DFT/AIMD 或实验比较；相关组成少量高温力误差只是初筛。
- 通过后才定温度和时长。MSD 拟合区间按扩散区间及敏感性确定，不能为了目标 Ea 改轨迹或调窗口。
- 一个结构可做探索性筛选，但不能据此报告非晶构型之间的不确定度；论文级推广时再决定独立结构采样需求。
- 优先复用已完成数据节约 points；保留余额 ≤100 时通知的既有要求，本次不更改监控或资源策略。
